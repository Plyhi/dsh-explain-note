Harness 里的 effect 为什么强调幂等？

幂等不是“不会出错”，而是“重复不会改变结果”

在 Harness 里，这个选择器是幂等的：同一轮里重复执行， 注册结果不会叠加，也不会把已经卸载的监听重新装回来。它关心的是“再做一次”的后果， 而不是单次执行成不成功。

所以像 ctx.effect() 这样的注册，通常会把清理函数作为返回值交出去： 卸载时按相反顺序收摊，下一轮重新注册时又从干净状态开始。这样 HMR、插件热重载、 会话切换都不会留下重复的副作用。 

ctx.effect(() => {
  const off = listen()
  return () => off()
}, 'my-plugin: lifecycle')

换句话说，幂等让“重放”变成安全的操作：你不需要知道这段代码被执行过几次， 只需要知道执行完之后的状态是一样的。
